QuickChat is a Java based messaging application developed for the Programming 1A.

the application allows users to:
Register an account
Log in to the system
Access the QuickChat menu
Send messages
Store messages
Validate recipient phone numbers
Validate message length
Generate unique Message IDs
Generate Message Hashes
Store messages in a JSOn file

Features implemented
Username validation
Password complexity validation
South african cell phone number validation

User Login
User authentication
Login status feedback

QuickChat Menu
Send Messages
Show recently sent messages
